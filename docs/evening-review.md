# Reading a run report

Optional. It does not gate the next slice. The agent has already continued.

1. Read `docs/runs/`. Status, Blocked, Provisional.
2. Answer anything under Blocked by writing it into the slice's *Decided for you*
   and, when it is a lasting choice, into `docs/decisions.md`.
3. Run `.cursor/commands/review-slice.md` in a fresh session when you want a
   second look. Read the blocking issues.
4. Try the report's commands when the slice has something you can open.
