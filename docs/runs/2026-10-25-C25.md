## Provisional decisions (taken, reversible)
- `ChecksBridge` is mixed into `RealBridge`, and `routes/__init__.py` notes that `checks.py` belongs to C25. Neither file is in the slice scope. The route cannot import the service, so the mixin is the same hook the other C slices use.
- A run calls `checks_runner.run_paragraph` with an injected `complete(system, user, tier)`. That is the C11 seam. No model injected means the check is not run and nothing is sent to Ollama or a cloud host. Wiring `LlmChatBackend` here would open a network path the tests must not take.
- The 2.0 cache is a JSON file under `.iterthink/checks/`, keyed by file version, prompt hash, check id, and path. `checks_runner`'s SQLite `ParagraphAnalysis` cache is not used. A denied egress call is not cached, so a later local run still works.
- Paragraphs are blank-line splits. A file with no text (a plan page) is one region `page 1` and is not OCR'd. Old text sent to the runner is empty; the current paragraph is new.
- The audit event type is `check`. The payload is the check id, the prompt version, and the model tier. It does not contain the file text. A cache hit does not write another event.
- A repeated result is labelled "advice, same version". The first result is "advice".
- Mod+Shift+C toggles `#checks-panel` from `check-symbols.js`. That script is loaded by the checks page. It is not in `home/head.html`, which this slice does not own, so the shortcut works on the checks page.

## Proposed changes to rules, decisions, other slices
