## Provisional decisions (taken, reversible)
- `iterthink/web/table_components.py` is not in the slice's file list. The suite has no JS runtime, and CI has no Node, so the chart SVG and the next CSV or JSON document live there. The custom elements in `static/js/` follow the same rules in the browser. (`table_components.py`)
- Inside an app frame the elements call `window.bridge.readFile` and `window.bridge.propose`. On a screen they POST the existing app call URL when the element has `data-call`. No new route.
- A changed cell uses `class="changed"` and `title` set to the previous value. The review spec says that. A5's table template marks the whole row instead.
- The browser CSV split does not unquote commas inside quotes. The Python chart uses the csv module. The form refuses a submit whose fields are all blank.
- `components.json` keeps the existing `md-preview` and `md-editor` entries and adds one example each for `data-table`, `simple-chart` and `form-fields`.

## Proposed changes to rules, decisions, other slices
