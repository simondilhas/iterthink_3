## Provisional decisions (taken, reversible)
- `snapshot` stores the whole tracked set you pass, not a delta. A later call
  that omits a path drops it from that version.
- `restore` copies every unlisted path from head. A listed path missing from
  the old version raises `SnapshotError`.
- Drafts are versions (`draft: true`) and show up in `history`. `head` skips
  them. `read_draft` refuses a non-draft.
- Timestamps are UTC with microseconds. If the clock does not move, the next
  stamp is one microsecond later so history order follows creation.
- The object write uses `Path.replace` after fsync (the same rename as
  `os.replace`; ruff prefers `Path.replace`).
- `persistence/__init__.py` no longer imports submodules. Coverage of
  `persistence.snapshots` otherwise reloads NumPy and collection dies.
  `from iterthink.persistence import store_db` still loads the submodule.
