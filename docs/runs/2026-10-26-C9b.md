## Provisional decisions (taken, reversible)
- Contract (done on the human's behalf, as asked in this session):
  `Bridge.model_glb(project, key, part)` returns a cached GLB, and
  `Bridge.diff_progress(project, path, base, target)` returns counters. The
  fake returns NotFound and `{}`.
- The GLBs are served at `/p/{id}/models/glb/{key}/{part}.glb`. The
  `details["glb"]` URLs stay project-relative (`/models/glb/...`).
- Counters live in `compare/ifc_progress.py`, keyed by the same content key
  as the GLB cache folder (`key_of` moved there from `ifc_glb._key`):
  elements, matched, reshaped, booleans, fallbacks, done. `matched` jumps
  from 0 to the total because `_compare` is one pass.
- The route decides "large" from `FileEntry.size` of the current file
  (`_BACKGROUND_BYTES = 50 MB`). The table arrives in one piece when the diff
  ends, not row by row.
- `base.html` import map now maps `three` and `three/addons/`, as the vendor
  note and `static/js/README.md` say.
- `partials/diff_model.html` rows carry `data-guid` so the table and the 3D
  view can select each other.
- The viewer rotates the model by −90° about X, because the GLB keeps IFC's
  Z-up coordinates.

## Surprises
- `ResizeObserver` did not fire in a background browser tab, so the canvas
  stayed 300×150. The stage now sizes itself when built and when a model is shown.
- The C9 web tests call the real bridge without `XDG_CONFIG_HOME`, so their
  GLBs land in the user's `~/.config/iterthink/ifc-glb`. The new C9b tests
  set it to a temporary folder; C9's tests could do the same.
