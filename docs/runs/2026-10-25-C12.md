## Provisional decisions (taken, reversible)
- `export` has no destination argument, so a delivery file always lands in `.iterthink/exports/<stem>-<version-short>.<ext>`. The short id is the first 12 characters of the source version. A folder the user picks is not on the bridge.
- The export is logged as `export` with `relation: derived_from`, the source path, and `source_version`. The index does not project that row yet.
- The export method has no actor, so the log line is `user:local`.
- PDF is one page of Helvetica text. Word uses the existing Markdown exporter and the bundled template when none is named.
- A returned file already inside the project is left byte for byte. One outside the project is copied in under its file name, then snapshotted, and is not overwritten when that name already differs.
- Word text is aligned with the text engine. The proposal is the aligned paragraphs. Excel becomes CSV and is proposed as the whole table.
