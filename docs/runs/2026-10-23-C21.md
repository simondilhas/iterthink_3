## Provisional decisions (taken, reversible)
- Tracking inheritance from a workspace `.iterthink` is not implemented. `load_settings` reads only the project's `project.yaml` `tracking` key, else the defaults (`disk_scan.py` `load_settings`). C15 owns settings inheritance.
- Input source `file` is the payload key `source`. The event schema has no top-level input field (`disk_scan.py` `_event`).
- The log sentence for a disk version event stays "edited {path}" because `describe()` lives in `proposals.py` (B1, outside this slice). History shows the snapshot description "changed on disk".
- The background watcher and the 60 s rescan do not start when `PYTEST_CURRENT_TEST` is set (`start_watching`). `make_project` and `open_folder` still scan synchronously.
- `moved_from` looks only at sibling folders of the project directory, and only after the source project has been scanned so its head no longer has the file. The reference is `{project_id}/{path}`.
- The SSE route is `GET /p/{id}/disk` and calls `bridge.disk_pull`, which is not on the Protocol. Web routes cannot import `services.disk_scan`. The project page does not include an EventSource; that template belongs to A1 and was left untouched. The partial is `project/_disk_changed.html`.
- A bool is rejected as `tracking.max_file_mb` (bool is a subclass of int) and falls back to 200.
