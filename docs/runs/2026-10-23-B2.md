## Tonight, by hand
1. `scripts/setup-agent-env.sh` from a fresh clone.
2. Copy a real project folder you are willing to try this on.
3. `uv run python -m iterthink.web` and open the printed link.
4. Type that folder under Open folder. Press Make project.
5. Open a Markdown file, change a sentence, save. History shows "edited …" and "started tracking".
6. Point Claude at iterthink. In `claude_desktop_config.json`:
   ```json
   {"mcpServers":{"iterthink":{"command":"uv","args":["run","--directory","/path/to/iterthink","python","-m","iterthink.mcp"],"env":{"ITERTHINK_PROJECTS":"/path/to/your/project"}}}}
   ```
7. Restart Claude and ask it to propose a change to that file. The file on disk stays as you left it.
8. In iterthink, open Proposals. Accept applies the text. Reject, with a reason, leaves the file. The log page says "Log intact".
9. Edit the file yourself after a new proposal, then Accept. The page says the proposal no longer fits the current file.
10. Open History, choose the earlier version, Restore. The file returns to that version, and the later one stays in history.

Reading a file through MCP stays off until `<project>/.iterthink/settings/project.yaml` says `egress: allowed`. Proposals work while it says `shielded`.
