## Provisional decisions (taken, reversible)
- `imported_from` is a log event (`relation`) with the working-copy path and version and the original path and version. The index does not project it yet.
- The original is snapshotted as received when it is not already the current version. The working copy is a normal save.
- The existing classifier calls a sparse PDF a plan, and a plan is not converted. A text PDF with no extractable body goes through `pdf_to_markdown_ocr`. A real scan with no text layer is classified as a plan by that classifier, so it is not sent to OCR.
- A dropped file whose name is new is not written until the page asks for a folder. `.` means the project folder.
- XLSX uses the first sheet only.
- `it-drop.js` is loaded from `home/head.html` so a drop on a project page reaches this slice. That file is outside the scope list.

## Proposed changes to rules, decisions, other slices
- CI should install the `ifc` extra.
- `bridge_real.py` is outside this slice's scope list and was edited so the page can call `work_on` and `drop_file`.
