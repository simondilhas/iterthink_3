## Provisional decisions (taken, reversible)
- The installed MCP SDK is 2.x. `FastMCP` was renamed to `MCPServer`
  (`mcp.server.mcpserver`). A6 uses `MCPServer`. Pinning `mcp<2` would edit
  `pyproject.toml`. (`iterthink/mcp/server.py`)
- A tool call that has an initialize handshake uses that client name
  (`agent:claude`). A direct call with no request uses `App.client_name`,
  then `agent:mcp`. (`_handshake_name`, `_actor`)
- The SDK wraps a list result as `{"result": [...]}`. Tests unwrap that key.
  A dict result is returned as itself.
