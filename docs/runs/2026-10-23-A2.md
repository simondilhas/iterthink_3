## Provisional decisions (taken, reversible)
- A checkpoint is an extra event after sequence 100, 200, …. One hundred
  `append` calls produce 101 lines. `checkpoint()` does not schedule another
  checkpoint.
- Another machine's log is left out of `heads` when its last line is missing
  a newline or its hash does not match. The append still succeeds.
- Lines are split on `\n` only, so a character that `str.splitlines` treats
  as a break stays inside the JSON line.
- Payload values other than str, int, bool, None, list and dict raise
  `ValueError`. Bool is accepted (it is checked before int).
- `machine` must be one path segment. `id` of an event is its `hash` (not a
  separate field).

## Proposed changes to rules, decisions, other slices
- Spec audit export (C13) says the product writes a standalone verifier.
  A2 ships `services/verify_log.py` as that script. C13 can copy it into an
  export; it should not grow a second hash implementation.
- `persistence/__init__.py` still imports `store_db` (NumPy). The first
  strict path under `persistence/` (A3) will hit the coverage double-load
  unless that package init stops importing submodules. A3 should do that
  in the same change, or `--full` cannot collect tests.
