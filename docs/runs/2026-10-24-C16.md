## Provisional decisions (taken, reversible)
- `RealBridge` inherits `DictationBridge` under the alias `Voice` (`bridge_real.py`). The route may only call the bridge, and the class line still fits in 100 characters. The file stays at 400 lines.
- The intent log gains `source` (`typed` or `voice`) from `take_source` (`intent.py`). One spoken session is consumed by the next classification. Chat and margin actions do not record it yet.
- `home/head.html` loads `it-dictation.js`. `c16-dictation.css` paints listening and transcribing; a verdict or an error keeps its colour.
- The hold key and hands-free flag are read from workspace then project `values.yaml`. `Ctrl+Space` is ignored and the default stands.
- Segments are transcribed once, when the hold ends, and streamed in order. The dot shows listening, then transcribing. A short click on the dot still opens proposals; a hold longer than 250 ms does not.
- Weights live in `<state>/models/whisper`. A temporary state directory uses the machine directory when that already has the model. The fixture test sets `dictation.model` to `tiny` so it does not download `small`.
- Samples are resampled to 16 kHz in memory and passed as an array. The installed PyAV rejects `metadata_errors`, which faster-whisper passes when given a file path.

## Surprises
- espeak-ng has no Swiss German voice, so Swiss German quality was not measured. The committed fixture is synthetic Standard German, "Guten Tag. Das ist ein Test." With language `de` and the tiny model the transcript is "Guten Tag. Das ist ein Test." A longer synthetic phrase, "Das Feuerkonzept ist fertig.", came back as "Das 2. Konzept." plus repeated "10." Do not promise Swiss German or compound words from the tiny model. The product default remains `small`, and that size was not run on the fixture.
- faster-whisper's file decoder calls `av.open` with `metadata_errors`, and this environment's PyAV raises `TypeError`. Arrays avoid that call.
- There is no microphone on this machine. The project page shows the steady dot and the line; Enter on "find the hall" still opens search. Hold-to-talk was not clicked in the browser. The stream, the insert, and the absent Enter are covered by the tests.
