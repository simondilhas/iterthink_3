## Provisional decisions (taken, reversible)
- The 1.x `run_impact_analysis` needs the old document store (numeric document and version ids). A 2.0 project does not have that store. This slice reads the seeded checks, asks `search.hybrid` for context in this project, and calls an injected model after `egress.check(..., "impact", tier)`. It does not call Ollama (`iterthink/services/impact_review.py`).
- The seed yaml has no file globs. A proposal that touches a `.md` or `.csv` file is treated as matched, and the proposal page requests impact on load. Other files get the button only.
- The cache is `<project>/.iterthink/impact/<proposal>-<check version>.json`. The version is the first 12 hex characters of the seed file's hash. A denial is not cached.
- The model is `use_impact_model`, so it does not hide the chat or intent setters.
- `review/body.html` includes the new partial, and `review.py` passes `impact_auto`. A5 owns those files. The advice has to sit next to the diff, and the route module cannot import the service (surfaces reach core only through the bridge).
