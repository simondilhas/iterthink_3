## Provisional decisions (taken, reversible)
- The seed topics are `discuss` and `change`. The menu labels them Discuss and Edit. No action in `defaults/prompts.yaml` has topic `evaluate`, so that group is not shown. The seed was not edited (`iterthink/services/margin_action.py`).
- A free instruction with no action id is an edit: it proposes, and the instruction is the reason. A discuss action with an instruction still only streams; the instruction is added to the prompt.
- When an instruction is empty, the proposal reason is the action label.
- A selection replaces its first match inside the paragraph. Otherwise the answer replaces the whole paragraph. Paragraphs come from `compare.margin.split_paragraphs`.
- The prompt version stored on the event is the sha256 of that action's system prompt. The model name is `router.model`. The paragraph and the answer are blobs. The event type is `margin` and the actor is the user. `proposals.describe` still prints the raw type, because that sentence list belongs to an earlier slice.
- The machine id is the stem of the project's only log, else `m-local`.
- A non-empty editor draft that differs from disk is saved with `bridge.save` before the model is called. An empty draft is not written, so a missing field cannot wipe the file.
- `paragraph` of -1 means "use the cursor offset" via `paragraph_index_at_offset`.
- Egress is `check(..., "chat", tier)`. A denial switches the call to `local` and does not call the router with company or cloud. The model itself is an injected `Router` whose `stream` runs on a daemon thread. The default router refuses without opening a socket. `llm_router.chat` was not called: that module is already over the size limit, `chat` is async, and tests must not reach Ollama.
- `/` at the start of an empty paragraph does not insert the character. It dispatches `it-recall` with `detail.path`. C3 is the listener.
- The document URL is `GET /p/{id}/doc/{path}`. The file list still opens `/f/`. `project/nav.html` is A1 and was not linked.
- If `.iterthink/prompts.yaml` exists it is read; otherwise the bundled seed is. This slice does not create that file.
