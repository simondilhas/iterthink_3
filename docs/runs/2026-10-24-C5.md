## Provisional decisions (taken, reversible)
- A chat version may include `.iterthink/chats/<id>.md` and nothing else under `.iterthink`. `persistence/snapshots.py` is outside the slice's file list; without that exception the chat file cannot be a version (`iterthink/persistence/snapshots.py`).
- The model is an injected router with `stream`, as on the document page. `egress.check(..., "chat", tier)` runs first. A denial uses `local`. `llm_router.chat` is not called.
- Search context is this project's hybrid index. Paths inside `.iterthink` are dropped. Cited paths are markdown links on the assistant section, and the same paths are stored in `references`.
- A live claim held by someone else makes the page read-only. A claim that has gone quiet is taken over, so the same person can send again (`iterthink/services/chats.py`).
- If two opens create the project index at once, the second open is tried again.
- Enter and Mod+Enter send. Shift+Enter is a line break. The sent line is shown in the thread immediately. The answer streams above the composer and stays in the thread when the stream closes.

## Proposed changes to rules, decisions, other slices
- `Index.__init__` should hold the per-database lock while it creates the file. The race is in `indexer.py`, which belongs to C1. This slice only retries once.
- `holder()` reports a quiet claim as free, while `acquire()` will not replace that file. Callers have to `take_over`. A note on C22 would help the next slice.
