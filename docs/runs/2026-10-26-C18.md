## Provisional decisions (taken, reversible)
- `iterthink` with no arguments opens the window (spec: Tech stack,
  `__main__.py` launches `desktop.py`). `--browser` keeps the old behaviour
  (serve and print a link). `iterthink mcp` serves MCP over stdio, because a
  packaged app has no `python -m iterthink.mcp`.
- The version comes from the installed package metadata. The spec copies
  that metadata into the bundle.
- `packaging/build_common.py` holds the data files, excludes and
  `collect_all` list for every platform. `packaging/entry.py` is the frozen
  entry script.
- macOS bundle identifier `ch.iterthink.app`. The entitlements file has only
  `com.apple.security.device.audio-input`; signing may need more
  (out of scope).
- Windows and macOS builds are windowed (`console=False`); Linux keeps a console.

## Proposed changes to rules, decisions, other slices
- `.cursorignore` lists `packaging/`. That pattern also matches
  `tests/v2/packaging/`, so the editor's agent tools cannot read or write
  either folder. The files were written from the shell. Suggest
  `/packaging/build/` and `/packaging/dist/` instead, or drop the line.
- `.github/workflows/desktop-build.yml` (human-owned), proposed:

```yaml
name: Desktop build
on:
  workflow_dispatch:
  push:
    tags: ["v*"]
env:
  UV_PYTHON: "3.12"
jobs:
  build:
    strategy:
      matrix:
        include:
          - { os: ubuntu-latest, spec: linux }
          - { os: windows-latest, spec: windows }
          - { os: macos-latest, spec: macos }
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v6
      - if: runner.os == 'Linux'
        run: sudo apt-get update && sudo apt-get install -y libgirepository-2.0-dev libportaudio2
      - run: uv sync --extra ifc --extra voice --extra package
      - if: runner.os == 'Linux'
        run: uv pip install pygobject
      - run: uv run pyinstaller packaging/iterthink-${{ matrix.spec }}.spec --noconfirm
      - if: runner.os != 'macOS'
        run: dist/iterthink/iterthink --version
      - if: runner.os == 'macOS'
        run: dist/iterthink.app/Contents/MacOS/iterthink --version
      - uses: actions/upload-artifact@v4
        with:
          name: iterthink-${{ matrix.spec }}
          path: dist/
```

## Surprises
- pywebview's GTK backend on Linux needs PyGObject, which is not in
  `uv.lock`. The local build picked up a hand-installed copy, and `uv sync`
  removes it again. The Linux window and build need it declared, for
  example as a Linux-only marker in the `package` extra (human-owned).
- Before this slice, `python -m iterthink --version` ignored the flag and
  started the server.
