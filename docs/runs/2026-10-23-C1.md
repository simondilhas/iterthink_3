## Provisional decisions (taken, reversible)
- The row writers live in `iterthink/services/index_store.py`. `indexer.py` on its own was over the 400-line limit (`docs/spec/conventions.md`).
- Meaning search stores a local hash vector in sqlite-vec and chunks text with `services/rag/chunking.py`. The ONNX weights fastembed expects are not in this tree. Loading them would download a model, and tests may not open a non-loopback socket. `semantic` therefore never calls fastembed.
- `hybrid` fuses keyword and semantic lists with reciprocal rank fusion, k = 60. The cross-encoder weights are not bundled, so the local reranker is not called.
- The index thread does not start when `PYTEST_CURRENT_TEST` is set. `search` and `log` call `update` before they read. Outside tests, each event starts a daemon thread.
- `intent_verdict` stores `accepted` or `rejected`. `contract/enums.py` only has `STABLE` and `NEW`. The contract file was not edited.
- `status = candidate` and the relations `proposes` and `contains` are the words in this slice. They are not in `contract/enums.py`.
- A content row with `content_kind` `project` is the source of each `contains` relation. That kind is not in the contract enums either.
- `/p` is recognised and removed. Each database is already one project, so the token does not filter further.
- The index refreshes when the log bytes or the set of snapshot files changes. A disk edit shows up after the scan records a version.
- Tables left empty: `app_settings`, `content_geometries`, `credential_vault`, `impact_annotations`, `paragraph_user_comments`, `paragraph_analysis`, `llm_usage_events`, `workspaces`, `projects`, `sync_outbox`, `rag_sync_outbox`. Filled: `content`, `content_relations`, `content_changes`, `content_file_links`, `files`, `audit_events`, `ix_fts`, `ix_trigram`, `ix_chunk`, `ix_vec`, `index_meta`.

## Surprises
- FTS5 trigram drops query tokens shorter than three characters. `"EI 9"` has to be passed as a phrase or it never reaches the trigram index, so `EI 9` would miss `EI 90`. Keyword search quotes the trigram probe.
- `unicode61 remove_diacritics 2` folds `Türliste` and `türliste` to the same token, which is what the contract test needs.
