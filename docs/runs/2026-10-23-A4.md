## Provisional decisions (taken, reversible)
- Paragraph kinds come from the existing heuristic (`_base_kind_from_diff`),
  not embeddings and not an LLM. A one-word change is `refined`.
- Word segments use `SequenceMatcher` on whitespace-separated words, the same
  pairing as `word_diff_html`, returned as `Segment`s.
- An empty side does not go through `compute_alignment`. An empty string
  would otherwise become a phantom paragraph.
- Plan overlap is reimplemented in `engine_plan.py` (IoU ≥ 0.25, lines within
  2pt). Engines may import `bridge` only, so they do not call
  `services/plan_text_diff.py`.
- A column daff adds is highlighted with row marker `+` and column action
  `+++`. That row is a cell change from empty to the new value.
- `diff()` returns kind `none` when the two byte strings are equal, before
  any engine runs. The reconstruction property calls `TextEngine` directly so
  identical paragraphs still produce stable blocks.
- `.docx` stays kind `document` (bridge) and is not run through the text
  engine. `formats.md` lists it under text; decoding a docx as UTF-8 is wrong.

## Proposed changes to rules, decisions, other slices
- `docs/spec/formats.md` describes `FormatEngine` as `extensions` +
  `diff(old, new, ctx) -> EngineResult` and `ContentChange` rows. The
  human-owned bridge and this slice use `kinds: tuple[FileKind, ...]` and
  `FileDiff`. A4 followed the bridge. A later spec edit should match it.
- `formats.md` says the plan engine is `services/plan_text_diff`. A4 copied
  the overlap rule into `compare/` so the engine stays free of `services`.
