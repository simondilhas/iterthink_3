## Provisional decisions (taken, reversible)
- `IfcEngine.diff` takes an optional `cache` directory. The A4 registry still calls `diff(path, before, after)`. When `cache` is omitted, GLBs go to the machine state directory under `ifc-glb/`.
- An IfcOpenShell file object must stay referenced until `create_shape` returns. Elements alone do not keep the file alive, and tessellating a collected file segfaults. `_world` and `_version_parts` hold the file for that call (`iterthink/compare/ifc_glb.py`).
- Boolean solids are copied into the source file, placed in world coordinates, and tessellated on a new proxy. An empty removed solid is volume 0.0 and is omitted from the GLB.
- The diff GLB URLs are `/models/glb/<key>/{before,after,diff}.glb`. No route serves them yet; that belongs with the viewer.

## Proposed changes to rules, decisions, other slices
- Vendor `three.module.js`, `GLTFLoader.js`, and `OrbitControls.js` in `static/vendor/`.
- CI should install the `ifc` extra (`uv sync --extra dev --extra ifc`). Same proposal as C9.
