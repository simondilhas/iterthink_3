- One proposal is automatic only when every file matches the same rule. Two different rules wait for a person.
- A spelling fix is the dictionary's correction of an unknown word, within edit distance 2. The dictionaries are German, English, French and Italian. Any other one-word swap waits (`iterthink/compare/change_classes.py`).
- Undo posts to the existing restore route and restores the proposal's baseline. The badge is a new partial included from `review/body.html` and `review/list.html`, which A5 owns.
- `who()` still prints `rule:<id>` on the actor line. It only special-cases `user:` and `agent:`. The badge carries the plain words.
