## Provisional decisions (taken, reversible)
- The seeded `appearance: dark` selects `theme.dark`. Those colours become the
  existing CSS variables (`--bg`, `--fg`, `--muted`, `--line`, `--accent`).
  The line spec's "white screen" is the light palette.
- On the start screen the line does not search. Search needs a project, so it
  starts on the project page. Enter there opens the top hit (C3 replaces this).
- Scripts are included from each page's head. `base.html` is human-owned, so
  the empty import map is unchanged.
- The file page has the same Files button as the project page, so Mod+E can
  open the panel from a file.
- `test_js_files_are_ts_checked` covers `static/js/*.js`. `README.md` stays.
- `launch` takes the webview module as a plain object. The installed
  pywebview module does not match a strict protocol, and the test passes a fake.

## Proposed changes to rules, decisions, other slices
- A5 should load `review-keys.js` from its own templates. The import map in
  `base.html` cannot be edited from a slice.
- A5's History button is already gated on a route named `panel`.

## Surprises
- FastAPI rejects a union of `HTMLResponse` and `RedirectResponse` unless the
  route sets `response_model=None`. The line route does that.
- Ruff forbids `Depends()` and `Form()` in argument defaults. They are module
  level names instead.
- The first browser pass showed the line and Open folder on one row, and
  Ctrl+E did nothing on a file page. Both are fixed: the folder form sits
  under the line, and the file page has the Files button.
