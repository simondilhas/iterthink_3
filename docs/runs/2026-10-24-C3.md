## Provisional decisions (taken, reversible)
- Rules run before the model, as the slice decided. The spec says the model first.
- The model is an injected `Router.complete`, not a call to `llm_router` from the route. Nothing injects one for the page, so an unmatched line is search until a caller calls `use_intent_model`.
- Confidence is stored as a string (`"0.40"`) because the log rejects floats.
- The line stays an `<input>`. Shift+Enter is prevented; an input cannot hold a newline.
- `it-recall` focuses `#line` and does not pass an open path.
- The idle dot is steady. The spec's start screen pulses; A1's stylesheet still does, and `c3-line.css` turns that off.
- Work typed on the start screen is placed with `make_project` of an absolute folder under `config.DOCUMENTS`. C23 is not on `dev`, and a relative path would be created in the current directory.
- A chat switch writes `.iterthink/chats/<id>.md` directly. `save` refuses `.iterthink`, and `chat_start` still belongs to C5.
- `home.py`, `projects.py`, `templates/home/index.html` and `templates/project/line.html` are outside the written scope. The start screen and the dot live there, and the tests cannot pass without those hooks. FakeBridge is unchanged.
