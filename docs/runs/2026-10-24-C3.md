## Provisional decisions (taken, reversible)
- Rules first, then the injected model. The spec's one line says the model runs first; this slice's decided section says rules first, and the acceptance examples expect no model call for those phrases (`iterthink/services/intent.py`).
- The model is `use_intent_model`, not `use_model`, so it does not hide `ChatsBridge.use_model`. It calls `Router.complete`, not `llm_router.chat`. A denial (`egress` none on company or cloud) does not call it.
- Confidence is stored as a string. The log rejects floats. The line text is `blob:<sha>`. The prompt id is `intent-v1`.
- The line stays an `<input>`. Shift+Enter does not submit. It cannot insert a newline in an input. Mod+K still focuses an input (`iterthink/web/static/js/the-line.js`).
- `it-recall` focuses `#line`. It does not yet pass the open document into classification.
- Idle dots are steady. Only `.dot.pulsing` animates. The spec's opening sentence shows a pulsing dot on the start screen; the state rule and this slice say steady when nothing is waiting (`iterthink/web/static/css/c3-line.css`).
- `line.py` renames A1's `POST /p/{id}/line` to `/p/{id}/line-keyword` at import, the same way the explorer took its path. `search.py` is not edited.
- The start screen calls `start_work` after the C23 new-project rule and the project-name match (`iterthink/web/routes/home.py`). `projects.py` passes `pulsing`. `project/line.html` and `home/index.html` load `the-line.js` and the quiet line. Those files are outside the written scope; the decided behaviour needs them.
- An app or task line stays on the page: "coming soon", search hits, and switch buttons. No redirect.
- A low-confidence model answer adds "not sure" when confidence is below 0.6.
