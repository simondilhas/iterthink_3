## Blocked — needs your answer
1. **Question:** CI runs `uv sync --extra dev` and does not install the `ifc` extra. These tests skip when IfcOpenShell is missing on a laptop, and fail when `CI` is set. Should the workflow install the extra?
   **Why it matters:** A fresh GitHub Actions run will fail at collection. `pyproject.toml` and `.github/workflows/ci.yml` are human-owned, so this slice cannot add the extra.
   **Options:** A) Change the workflow to `uv sync --extra dev --extra ifc`. B) Keep skipping in CI as well. **I'd pick:** A, because the slice says a missing extra fails in CI, and the engine cannot run without IfcOpenShell.
2. **Question:** Review can accept or reject a whole proposal. The spec also wants a verdict on each change. The bridge has no per-change verdict.
   **Why it matters:** The model table is read-only. There is no per-row accept or reject.
   **Options:** A) Add per-change verdicts to the bridge. B) Keep whole-proposal verdicts. **I'd pick:** A, when the contract grows. Until then the table stays read-only, which this slice already decided.

## Provisional decisions (taken, reversible)
- The spec's `FormatEngine.diff(old, new, ctx)` is not what `compare/engines.py` calls. The engine uses the registry that A4 shipped: `diff(path, before, after) -> FileDiff` with `kinds = ("model",)`.
- Geometry helpers live in `iterthink/compare/engine_ifc_geom.py` so `engine_ifc.py` stays under 400 lines.
- `queryIfc` and `ifcProperties` are not bridge methods. Apps reach them through the allowlist in `app_calls.py` and `app_validate.py`, and the names were added to `app-bridge.js`.
- The review partial is included from `history/diff.html`, and `diff_view` in `history.py` passes model rows. Both belong to A5.
- `propose` still refuses an `.ifc` path. The review test stores the draft with `proposals.create`, which is how a model proposal can exist without treating IFC as an editable text file.
- Category colours are `--it-cat-*` aliases of the existing theme tokens. The palette has no separate colour for each category.
- Shape hashes use local coordinates rounded to 1 mm. Placement is the 4×4 matrix in millimetres. Volume is the tessellated mesh in cubic metres, rounded to 0.001.

## Proposed changes to rules, decisions, other slices
- CI should install the `ifc` extra (`uv sync --extra dev --extra ifc`).
- The bridge should grow `queryIfc` and `ifcProperties`, and a per-change verdict, when the contract is next edited.
- `docs/spec/formats.md` still shows `diff(old, new, ctx) -> EngineResult`. The registry uses `FileDiff`.
